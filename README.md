## 📝 简介

**XnanTool**初心是一个为 ComfyUI 打造的市面上插件因原作者不更，或者更新慢，导致功能不足的问题，这里提供了拓展方案。
特性：同样的节点，功能更丰富，更优化，bug少，更稳定。
备注：其他热门插件中一些很基础的节点，就不会制作了，还是用原来的节点，如果粉丝需求多，我再去制作。

## 特别说明
版本在0.8.0，更新了大量的节点，和优化的节点，如果遇到节点报红色错误，请先尝试新建节点 ，因为这是版本更新导致的。
由于comfyui在0.20版本原生支持了sam3，所以本插件的sam后续会进行重构或其他调整。
## ✨ 功能特性

### 🌐 API类节点
集成了火山引擎、阿里云百炼、魔搭社区等平台的AI能力，提供了文生图、图生图、文本生成、视觉理解、视频生成等多种功能。

### 🎯 YOLO和SAM类节点
集成了YOLOv8系列目标检测模型和SAM图像分割模型，提供了目标检测、图像裁切、背景移除等功能。

### 📏 预设管理类节点
提供了丰富的预设管理功能，包括尺寸预设、比例预设、提示词预设、随机提示词生成等，帮助用户快速选择常用参数。

### 🖼️ 图像处理类节点
提供了丰富的图像处理功能，包括图像加载、格式转换、尺寸调整、图像合并、网格分割等。

### 🎬 媒体处理类节点
提供了丰富的视频和音频处理功能，包括视频转GIF、视频转MP4、视频转音频、图片转GIF、视频帧提取等。

### 🦙 Ollama类节点-兼容类节点
集成了Ollama大语言模型服务，提供了连接配置、参数配置、文本生成和聊天对话等功能。

### 🛠️ 实用工具类节点
提供了一些辅助功能，包括值切换、随机执行、批量文件操作、文本处理、时间获取、文件夹管理等实用工具。

### ⚙️ 插件设置类节点
提供了插件版本检查、版本信息展示等功能，方便用户管理和更新插件。


## 📥 安装方法

### 方法一：直接克隆
```bash
# 克隆仓库到 ComfyUI 的 custom_nodes 目录
git clone https://github.com/otsluo/comfyui-xnantool.git
# 安装依赖: pip install -r requirements.txt
# 重启 ComfyUI 即可使用
```
```bash
# 加速镜像
git clone https://gitcode.com/weixin_45738527/comfyui-xnantool.git
# 安装依赖: pip install -r requirements.txt
# 重启 ComfyUI 即可使用
```

### 方法二：手动安装
1. 💾 下载本项目的压缩包
2. 📂 将解压后的 `comfyui-xnantool` 文件夹复制到 ComfyUI 的 `custom_nodes` 目录中
3. 💻 安装依赖: `pip install -r requirements.txt`
4. 🔄 重启 ComfyUI 后即可在节点菜单中找到相关功能
